# Add-lyrics-in-mp3-files-library
A collection of python and linux shell scripts to add lyrics (both synced and plain) in the ID3 tag of my mp3 library

Every time I download an MP3 album or a Discography or a file for [my free music streamer](http://spotifuck.online) I want the files filled-in with lyrics.
The best source (free and available) is [LRCLIB](https://lrclib.net/), but other services are good too!

In this repository I collect all the Python and Shell scripts I use to manage ID3 tag in MP3 files and their tassonomy.
